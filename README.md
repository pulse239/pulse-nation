# Pulse Nation Roleplay

Offizielle Community-Webseite des deutschen GTA V FiveM Roleplay-Servers Pulse Nation.

## Webseite

Die Seite wird über GitHub Pages veröffentlicht:

https://pulse239.github.io/pulse-nation/

## Inhalt

- Servervorstellung und Highlights
- Fraktionen und Möglichkeiten
- Galerie mit echten Community-Aufnahmen
- Einreiseinformationen
- Discord- und Teamspeak-Zugang

Die Webseite ist statisch aufgebaut und benötigt keinen Build-Schritt. Änderungen an `main` werden über GitHub Pages veröffentlicht.
